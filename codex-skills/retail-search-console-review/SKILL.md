# Retail Search Console Review

Confirm the exact property and use read-only access, or use a local CSV export. For India, filter country and device where available. Compare equal complete date ranges and include both absolute and percentage changes when mathematically meaningful.
For total CTR, divide total clicks by total impressions rather than averaging row CTRs. For total property metrics, prefer property totals over a sum of query rows, which can omit anonymised searches. If an export lacks country or device columns, mark the requested segment unavailable. Keep exports and credentials local.
Example: distinguish published URLs absent from a collection sitemap from URLs reported as unindexed in Search Console.

Save findings and proposed edits in a local draft. Include current and proposed values, evidence, and the checks to run after release. Live changes and publishing require the user’s approval after reviewing the draft.
